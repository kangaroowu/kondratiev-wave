# 🌊 涛动周期论 · 康波周期 Skill

> **"人生财富靠康波"——周金涛**

一个面向 AI Agent 的康德拉季耶夫长波（Kondratiev Wave）与周金涛"涛动周期论"专家知识库，用于长周期视角下的宏观判断、资产配置与人生财富规划。

## 🎯 这是什么

本 Skill 是一个结构化知识包，可安装到支持 [Skills CLI](https://skills.sh/) 的 AI Agent 中，使其具备康波周期专家级别的分析能力：

- 🔄 **周期定位**：判断当前处于第几波康波、哪个阶段
- 📊 **资产配置**：基于四阶段模型给出股/债/金/商品/房产配置建议
- 📖 **历史对照**：五轮康波详细数据与周金涛预测回顾
- ⚠️ **风险提醒**：方法论局限、常见误区与使用边界

## 📦 安装

```bash
npx skills add kangaroowu/kondratiev-wave
```

## 🧠 核心知识体系

### 康波四阶段

| 阶段 | 经济特征 | 最佳资产 |
|---|---|---|
| **繁荣** | 技术创新扩散，增长强劲 | 股票 📈 |
| **衰退** | 通胀上行，产能过剩 | 大宗商品 🛢️ |
| **萧条** | 金融危机，债务出清 | 现金 + 黄金 + 债券 🏦 |
| **回升** | 旧产能出清，新技术孕育 | 股票（新经济）📊 |

### 周金涛核心论断

1. **"人生发财靠康波，人生破产也靠康波"**——出生时点决定周期机会
2. **大宗商品的长期底部在萧条末端**——最确定的配置机会
3. **黄金在萧条与回升阶段表现最佳**——对冲信用货币危机
4. **三周期嵌套**：康波（50–60年）+ 朱格拉（8–10年）+ 基钦（40个月）

### 五轮康波对照

| 轮次 | 起始 | 驱动技术 | 标志事件 |
|---|---|---|---|
| 第一波 | ~1780 | 蒸汽机/纺织 | 英国工业革命 |
| 第二波 | ~1840 | 钢铁/铁路 | 铁路狂潮 |
| 第三波 | ~1890 | 电力/化工 | 第二次工业革命 |
| 第四波 | ~1940 | 汽车/石化 | 战后繁荣 |
| 第五波 | ~1980 | 信息技术 | 互联网革命 |
| 第六波 | ~2020? | AI/新能源/生物 | 推断中 |

## ⚠️ 重要提醒

- 康波是**长周期框架**（50–60 年），不适合短期择时
- 周金涛 2016 年英年早逝，其**具体时间点预测需结合最新数据校准**
- 区分**理论框架**与**具体预测**：框架有学术基础，拐点年份是推断
- 任何投资建议需附加**风险提示**，资产配置需结合个人情况
