# 🌊 涛动周期论 · 康波周期 Skill

> **"人生发财靠康波"——周金涛**

一个面向 AI Agent 的康德拉季耶夫长波（Kondratiev Wave）与周金涛"涛动周期论"专家知识库，用于长周期视角下的宏观判断、资产配置与人生财富规划。

## 🎯 这是什么

本 Skill 是一个结构化知识包，可安装到支持 Skills CLI 的 AI Agent 中，使其具备康波周期专家级别的分析能力：

- 🔄 **周期定位**：判断当前处于第几波康波、哪个阶段
- 📊 **资产配置**：基于四阶段模型给出股/债/金/商品/房产配置建议
- 📖 **历史对照**：五轮+第六波康波详细数据与周金涛预测回顾
- 🤖 **第六波分析**：AI+新能源+生物科技三驾马车、赛道图谱、2026-2070时间表
- 🏛️ **家族策略**：洛克菲勒/罗斯柴尔德/李嘉诚等顶级家族跨周期策略解构
- 📋 **投资手册**：按年龄层的配置建议、六大可操作策略、2026-2040周期日历
- 🏠 **房地产周期**：东西半球房地产周期时差与投资含义
- 🥇 **黄金定价**：商品/金融/货币三属性定价模型
- 🌍 **共生模式**：主导国/追赶国/资源国三类国家分析框架
- ☀️ **天文周期**：太阳黑子与经济周期的四层对应关系
- 🧠 **人性与周期**：周期本质是人性贪婪与恐惧的轮回
- ⚠️ **风险提醒**：方法论局限、常见误区与使用边界

## 🧠 核心知识体系

### 康波四阶段

| 阶段 | 经济特征 | 最佳资产 |
|---|---|---|
| **繁荣** | 技术创新扩散，增长强劲 | 股票 📈 |
| **衰退** | 通胀上行，产能过剩 | 大宗商品 🛢️ |
| **萧条** | 金融危机，债务出清 | 现金 + 黄金 + 债券 🏦 |
| **回升** | 旧产能出清，新技术孕育 | 股票（新经济）📊 |

### 周金涛核心论断

1. **"人生发财靠康波，人生破产也靠康波"**——出生时点决定周期机会
2. **大宗商品的长期底部在萧条末端**——最确定的配置机会
3. **黄金在萧条与回升阶段表现最佳**——三属性定价模型
4. **四周期嵌套**：1康波 = 3房地产 = 9朱格拉 = 18基钦
5. **四周期嵌套商品定价**：康波→产能周期→超级周期→涛动周期
6. **宿命与反抗**：长周期趋势不可逆，中短周期制造反弹
7. **周期即人性**：周期本质是人性贪婪与恐惧的轮回
8. **天文周期对应**：太阳黑子四层循环对应四类经济周期
9. **共生模式**：资源国/制造国/货币国三类国家分工体系
10. **罗斯托工业化**：中国经济奇迹的制度外解释

### 四周期嵌套商品定价模型

| 层级 | 周期 | 长度 | 定价作用 |
|---|---|---|---|
| 第一层 | 康波周期 | 50–60年 | 决定商品长期趋势方向 |
| 第二层 | 产能周期 | ~30年 | 决定产能投资与供给 |
| 第三层 | 超级周期 | ~20年 | 决定价格超级波动 |
| 第四层 | 涛动周期 | ~6.6年 | 决定中级价格波动 |

|---|---|---|---|

| 厄尔尼诺循环 | 2–7年 | 基钦周期 | ~40个月 |

### 五轮+第六波康波对照

| 轮次 | 起始 | 驱动技术 | 标志事件 |
|---|---|---|---|
| 第一波 | ~1780 | 蒸汽机/纺织 | 英国工业革命 |
| 第二波 | ~1840 | 钢铁/铁路 | 铁路狂潮 |
| 第三波 | ~1890 | 电力/化工 | 第二次工业革命 |
| 第四波 | ~1940 | 汽车/石化 | 战后繁荣 |
| 第五波 | ~1980 | 信息技术 | 互联网革命 |
| 第六波 | ~2020 | AI/新能源/生物 | 多技术并联驱动 |

### 康波四季模型

| 季节 | 阶段 | 增长-通胀 | 最佳资产 |
|---|---|---|---|
| 🌱 春季 | 回升期 | 增长↑ 通胀↓ | 股票（成长股） |
| ☀️ 夏季 | 繁荣期 | 增长↑ 通胀↑ | 房地产、实物资产 |
| 🍂 秋季 | 衰退期 | 增长↓ 通胀↑ | 黄金、大宗商品 |
| ❄️ 冬季 | 萧条期 | 增长↓ 通胀↓ | 现金/国债（早期）→ 核心资产抄底（晚期） |

### 第六轮康波三驾马车

| 驱动力 | 定位 | 渗透阶段 |
|---|---|---|
| 🤖 人工智能 | 核心引擎（蒸汽机级GPT） | 2022-2027基建期 → 2027-2035平台期 → 2035-2050全面渗透 |
| ⚡ 新能源 | 基础支撑 | 光伏已低于火电，核聚变~2035商业化 |
| 🧬 生物科技 | 价值增量 | 基因编辑+AI药物发现+抗衰老6000亿美元市场 |

### "老钱密码"五大共性

| 维度 | 共性做法 | 重要性 |
|---|---|---|
| 制度 | 家族信托 + 家族办公室 | 最高 |
| 实物锚定 | 地产/矿/基础设施占比30-50% | 高 |
| 现金纪律 | 保持15-25%流动性 | 高 |
| 逆向操作 | 萧条期反向买入 | 高 |
| 全面分散 | 地域/行业/币种/资产类别 | 最高 |

### 黄金三属性定价模型

| 属性 | 驱动因素 | 与金价关系 |
|---|---|---|
| 商品属性 | 供需 | 长期底部支撑 |
| 金融属性 | 实际利率 | 反向关系（利率↓→金价↑） |
| 货币属性 | 美元信用 | 对冲信用危机，萧条期最强 |

## ⚠️ 重要提醒

- 康波是**长周期框架**（50–60 年），不适合短期择时
- 周金涛 2016 年英年早逝，其**具体时间点预测需结合最新数据校准**
- 区分**理论框架**与**具体预测**：框架有学术基础，拐点年份是推断
- 任何投资建议需附加**风险提示**，资产配置需结合个人情况
- 周金涛承认：康波理论是统计规律，没有严密理论体系
- 本 Skill 仅供学习研究，不构成投资建议
