# 康波四阶段详细模型

## 阶段总览

每个康波周期约 50–60 年，分为四个阶段，每阶段约 10–15 年。周金涛强调：**长波决定方向，中短波（朱格拉、基钦）决定节奏**。

### 增长与通胀的动态关系（周金涛核心框架）

> "任何周期的机制都可以理解为价格对增长的反制，康波也不例外。但是康波中通胀对增长的抑制是十分暴力的，基本上以冲击的形式完成。"

| 阶段 | 增长 | 通胀 | 关系 |
|---|---|---|---|
| 繁荣 | 高增长 | 低通胀 | 技术提升效率，增长未引发资源约束 |
| 衰退前半期 | 高增长 | 高通胀 | 效率降低但仍按原速运行，投资增加 |
| 衰退后半期 | 增长回落 | 滞胀 | 通胀顽固，增长放缓 |
| 萧条 | 增长停滞 | 通缩↔滞胀交替 | 从滞胀向通缩转换，约10年 |
| 回升 | 温和复苏 | 低位通缩 | 旧产能出清，新技术孕育 |

## 一、繁荣阶段（Prosperity）

### 经济特征
- 重大技术创新群开始产业化
- GDP高增长，生产率快速提升（全要素生产率加速）
- 通胀温和，利率稳定
- 新产业涌现，就业充分
- **高增长伴随低通胀**——新技术提高效率，增长未引发资源约束

### 典型事件
- 资本大量涌入新技术领域
- 股市进入长牛
- 出现"新经济"叙事
- 风险偏好极高

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 股票 | ★★★★★ | 科技股领涨 |
| 商品 | ★★ | 温和上行 |
| 债券 | ★★★ | 收益率上行 |
| 黄金 | ★ | 表现疲弱 |
| 房产 | ★★★★ | 繁荣后期上涨 |

### 历史案例
- 1990s：互联网繁荣
- 1950s–1960s：战后黄金年代
- 1920s：汽车/电力繁荣

### 繁荣转折信号
- **全要素生产率增速见顶回落**（如美国2003年全要素生产率见顶，2002年大宗商品牛市启动）
- 新技术对生产率提升边际递减
- 追赶国工业化加速，资源需求边际上升

## 二、衰退阶段（Recession，注意非日常"衰退"）

### 经济特征
- 增长见顶回落但仍正增长
- **通胀显著上行**（最关键特征）
- 产能过剩显现
- 利率持续走高
- **衰退前半期**：高增长引发高通胀
- **衰退后半期**：滞胀

### 两次冲击模式（周金涛核心发现）

康波衰退阶段最复杂的特征——**两次冲击**：

1. **第一次冲击**：标志性经济危机，确认康波进入衰退
   - 第四波：1971-1973年布雷顿森林体系崩溃
   - 第五波：2008年美国次贷危机
2. **间歇期**：暂时稳定阶段，货币宽松主导
3. **第二次冲击**：更多发生在新兴经济体或资源国
   - 第四波：1979年石油危机
   - 第五波：2015年二季度（A股暴跌/商品暴跌/人民币贬值）

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 商品 | ★★★★★ | **最佳配置阶段**，出现超级牛市 |
| 黄金 | ★★★★ | 抗通胀首选 |
| 股票 | ★★ | 见顶后走弱 |
| 债券 | ★ | 利率上行，价格跌 |
| 房产 | ★★★ | 见顶 |

### 历史案例
- 2000–2008：原油/铜/铁矿石超级牛市
- 1966–1975：70年代滞胀，黄金从35→800美元
- 1913–1920：一战期间商品暴涨

## 三、萧条阶段（Depression）

### 经济特征
- **金融危机爆发**（最关键特征）
- 通缩与滞胀反复交替
- 增长停滞甚至负增长
- 利率持续走低至零下限
- **货币消灭机制启动**——流动性从过剩到消灭

### 货币消灭机制（周金涛理论）
1. **第一阶段**：流动性大量过剩，涌入创新领域（创新泡沫）
2. **第二阶段**：流动性脱虚向实，涌入房地产，黄金上涨
3. **第三阶段**：萧条来临，资产只能相对保值，最佳配置为**现金加黄金**

### 典型事件
- 大型金融机构倒闭
- 资产价格大幅下跌
- 央行量化宽松
- 财政大刺激
- 财富大幅缩水

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 现金 | ★★★★★ | **现金为王** |
| 债券 | ★★★★ | 利率下行，价格涨 |
| 黄金 | ★★★★ | 避险首选 |
| 股票 | ★ | 大跌，但**萧条末端是历史性买点** |
| 商品 | ★ | 持续下跌，**底部就在萧条末端** |
| 房产 | ★★ | 下跌 |

### 历史案例
- 2008–2020：金融危机、欧债危机、疫情冲击
- 1929–1940：大萧条
- 1873–1885：长萧条

### 周金涛核心观点
> **萧条阶段是现金为王的时代，但萧条末端是大宗商品历史性底部，也是抄底风险资产的最佳时机。**
>
> "2018年最佳的资产就是现金加黄金。"

## 四、回升阶段（Recovery / Expansion）

### 经济特征
- 旧产能出清完成
- 下一代技术开始孕育
- 增长温和复苏
- 通胀低位，利率稳定

### 典型事件
- 新技术企业崛起
- 股市稳步走牛
- 信用重新扩张
- 风险偏好回升
- 可能出现新兴经济体复兴（如20世纪80-90年代亚洲四小龙）

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 股票 | ★★★★ | 筑底回升，新经济领涨 |
| 债券 | ★★★ | 仍稳健 |
| 黄金 | ★★★ | 趋于平稳 |
| 商品 | ★★ | 底部震荡 |
| 房产 | ★★★ | 复苏 |

### 历史案例
- 1982–1990：里根/撒切尔改革，PC革命
- 1940s–1950s：战后重建

## 阶段转换的关键信号

| 转换点 | 关键信号 |
|---|---|
| 繁荣→衰退 | 全要素生产率见顶、通胀突破长期均值上行、央行开始持续加息 |
| 衰退→萧条 | 重大金融机构破产、资产价格崩盘、第二次冲击出现 |
| 萧条→回升 | 大宗商品触底、信用利差收窄、新技术突破 |
| 回升→繁荣 | 新技术大规模商业化、生产率数据跃升 |

## 阶段判别的指标体系

1. **通胀与利率**：长期趋势的转折
2. **大宗商品价格**：长期顶部/底部
3. **全要素生产率**：繁荣期加速，萧条期放缓（美国2003年见顶，1966年见顶）
4. **金融危机频率**：萧条期集中爆发
5. **技术创新强度**：专利数、研发投入、新产业GDP占比
6. **产能利用率**：1983年是第四波萧条结束的低点

## 五、康波萧条期的滞胀与货币消灭机制

### 萧条期的完整演化路径

```
繁荣期末 → 流动性充裕 → 资产荒（钱多但无收益率）
  → 转折点（2015年式） → 滞胀展开
  → 流动性差的资产无人接盘 → 货币消灭机制启动
  → 资产价格下跌 → 通缩深化
  → 直到新信用扩张启动 → 进入回升期
```

### 货币消灭机制三阶段（详细版）

| 阶段 | 机制 | 表现 | 案例 |
|---|---|---|---|
| **第一阶段** | 资产价格暴跌 | 抵押品价值缩水，杠杆断裂 | 2008年次贷/MBS暴跌 |
| **第二阶段** | 债务违约 | 银行资产负债表收缩，信用收缩 | 雷曼破产→信用冻结 |
| **第三阶段** | 货币供给减少 | 存款消失，通缩深化 | M2增速骤降 |

### 滞胀阶段的投资含义

1. **滞胀前的信号**：
   - 央行放水不再有效（"资产荒"）
   - 流动性充裕但无收益率
   - 一线房产/新兴产业被追捧（"消灭中产财富的方法"）

2. **滞胀中的操作**：
   - 持有流动性好的资产
   - 远离流动性差的资产（非核心房产、新三板等）
   - 第一目标是保值，第二目标是流动性

3. **货币消灭后的机会**：
   - 资产价格极度低估
   - 拥有现金流者可以低价买入
   - 周金涛建议："赶紧发债"，以较低价格买进资产

### 周金涛的"消灭中产"警告

周金涛在2016年演讲中明确警告：
- 买一线房产和投新兴产业是"消灭中产阶层财富的方法"
- 2014年后不买房，房地产周期反弹是"熊市中的B浪"
- "赚钱不重要，第一目标是保值，第二目标是流动性"
- "未来5年（2016-2021）是资产的下降期"

## 六、多周期共振底部

### 共振底部的定义
当康波、朱格拉、基钦（甚至库兹涅茨）三个或四个周期在同一时间节点共同向下，形成"共振底部"——这是最危险也是最具历史意义的时刻。

### 历史共振底部

| 时间 | 共振周期 | 结果 |
|---|---|---|
| 1929-1933 | 康波萧条+朱格拉下行+基钦下行 | 大萧条 |
| 1973-1975 | 康波衰退+朱格拉下行+基钦下行 | 石油危机+滞胀 |
| 2008-2009 | 康波衰退二次冲击+朱格拉下行+基钦下行 | 金融危机 |
| 2019? | 康波萧条末+库兹涅茨下行+朱格拉下行+基钦下行 | 周金涛预测的共振低点 |

### 周金涛对2019年的判断
- 2019年是房地产周期、朱格拉周期、库存周期的低点
- 三周期低点重合共振
- 是1985年后出生者人生第一次财富机会
- 大宗商品将见历史性底部

### 共振底部的投资意义
- 最危险的时刻=最大的机会
- "在别人恐惧时贪婪"的周期版
- 但需要极大的勇气和充足的现金
