# 康波四阶段详细模型

## 阶段总览

每个康波周期约 50–60 年，分为四个阶段，每阶段约 10–15 年。周金涛强调：**长波决定方向，中短波（朱格拉、基钦）决定节奏**。

## 一、繁荣阶段（Prosperity）

### 经济特征
- 重大技术创新群开始产业化
- GDP 高增长，生产率快速提升
- 通胀温和，利率稳定
- 新产业涌现，就业充分

### 典型事件
- 资本大量涌入新技术领域
- 股市进入长牛
- 出现"新经济"叙事
- 风险偏好极高

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 股票 | ★★★★★ | 科技股领涨 |
| 商品 | ★★ | 温和上行 |
| 债券 | ★★★ | 收益率上行 |
| 黄金 | ★ | 表现疲弱 |
| 房产 | ★★★★ | 繁荣后期上涨 |

### 历史案例
- 1990s：互联网繁荣
- 1950s–1960s：战后黄金年代
- 1920s：汽车/电力繁荣

## 二、衰退阶段（Recession，注意非日常"衰退"）

### 经济特征
- 增长见顶回落但仍正增长
- **通胀显著上行**（最关键特征）
- 产能过剩显现
- 利率持续走高

### 典型事件
- 大宗商品出现超级牛市
- 股市见顶后剧烈震荡
- 资源国/资源股大放异彩
- 央行被迫紧缩

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 商品 | ★★★★★ | **最佳配置阶段** |
| 黄金 | ★★★★ | 抗通胀首选 |
| 股票 | ★★ | 见顶后走弱 |
| 债券 | ★ | 利率上行，价格跌 |
| 房产 | ★★★ | 见顶 |

### 历史案例
- 2000–2008：原油/铜/铁矿石超级牛市
- 1966–1975：70 年代滞胀，黄金从 35→800 美元
- 1913–1920：一战期间商品暴涨

## 三、萧条阶段（Depression）

### 经济特征
- **金融危机爆发**（最关键特征）
- 通缩压力，债务出清
- 增长停滞甚至负增长
- 利率持续走低至零下限

### 典型事件
- 大型金融机构倒闭
- 资产价格大幅下跌
- 央行量化宽松
- 财政大刺激
- 财富大幅缩水

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 现金 | ★★★★★ | **现金为王** |
| 债券 | ★★★★ | 利率下行，价格涨 |
| 黄金 | ★★★★ |避险首选 |
| 股票 | ★ | 大跌，但**萧条末端是历史性买点** |
| 商品 | ★ | 持续下跌，**底部就在萧条末端** |
| 房产 | ★★ | 下跌 |

### 历史案例
- 2008–2020：金融危机、欧债危机、疫情冲击
- 1929–1940：大萧条
- 1873–1885：长萧条

### 周金涛核心观点
> **萧条阶段是现金为王的时代，但萧条末端是大宗商品历史性底部，也是抄底风险资产的最佳时机。**

## 四、回升阶段（Recovery / Expansion）

### 经济特征
- 旧产能出清完成
- 下一代技术开始孕育
- 增长温和复苏
- 通胀低位，利率稳定

### 典型事件
- 新技术企业崛起
- 股市稳步走牛
- 信用重新扩张
- 风险偏好回升

### 资产表现
| 资产 | 表现 | 说明 |
|---|---|---|
| 股票 | ★★★★ | 筑底回升，新经济领涨 |
| 债券 | ★★★ | 仍稳健 |
| 黄金 | ★★★ | 趋于平稳 |
| 商品 | ★★ | 底部震荡 |
| 房产 | ★★★ | 复苏 |

### 历史案例
- 1982–1990：里根/撒切尔改革，PC 革命
- 1940s–1950s：战后重建

## 阶段转换的关键信号

| 转换点 | 关键信号 |
|---|---|
| 繁荣→衰退 | 通胀突破长期均值上行、央行开始持续加息 |
| 衰退→萧条 | 重大金融机构破产、资产价格崩盘 |
| 萧条→回升 | 大宗商品触底、信用利差收窄、新技术突破 |
| 回升→繁荣 | 新技术大规模商业化、生产率数据跃升 |

## 阶段判别的指标体系

1. **通胀与利率**：长期趋势的转折
2. **大宗商品价格**：长期顶部/底部
3. **金融危机频率**：萧条期集中爆发
4. **技术创新强度**：专利数、研发投入、新产业 GDP 占比
5. **生产率增速**：繁荣期加速，萧条期放缓
